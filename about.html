Một số ngôn ngữ lập trình đã học

Python
Ngôn ngữ lập trình phổ biến, dễ học, được sử dụng rộng rãi trong nhiều lĩnh vực như phát triển web, khoa học dữ liệu, trí tuệ nhân tạo và tự động hóa.
JavaScript
Ngôn ngữ lập trình chủ yếu được sử dụng để phát triển các ứng dụng web tương tác và động. Nó cho phép tạo ra các hiệu ứng trực quan, xử lý sự kiện và tương tác với người dùng trên trình duyệt.
HTML/CSS
HTML (Hypertext Markup Language) là ngôn ngữ đánh dấu được sử dụng để xây dựng cấu trúc của trang web. CSS (Cascading Style Sheets) là ngôn ngữ định kiểu được sử dụng để tạo kiểu dáng và bố cục cho trang web.
C++
Ngôn ngữ lập trình mạnh mẽ, được sử dụng rộng rãi trong phát triển phần mềm hệ thống, trò chơi điện tử, ứng dụng nhúng và các ứng dụng yêu cầu hiệu suất cao.
